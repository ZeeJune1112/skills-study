# 03: 发现局域网房间并完成双人对局

**What to build:** 两台同一局域网内的 Windows 设备使用同一个程序。房主开双人房并获得房间标识，访客从大厅发现房间，入房后上席，房主开局，双方完成一局。房内消息与连接方式解耦，为后续异地对战预留传输接口。

**Blocked by:** 01 双击单文件程序，完成人机首局

**Status:** resolved

- [x] 房主创建双人房后默认坐黑席，房间显示可辨认的房间标识。同一局域网的访客可在大厅自动发现并选择加入。
- [x] 访客先进入观众席，再于开局前选择空闲的黑席或白席。房主在两个对战席均有人后可开始对局。
- [x] 两台设备显示一致的棋盘、棋色、轮次和终局结果，双方可轮流完成一局。房主校验入房、上席及落子，旁观、非本人轮次、占用交点等非法落子不会改变棋局。
- [x] 局域网发现与房内通信可独立验证。房间会话可通过测试传输交换操作和状态消息，实际联机使用局域网传输。

## Answer

`1ab96e1` 实现双人房，18 项自动化检查通过。同一台 Windows 11 的两个发布版实例经 UDP 发现房间并通过真实 TCP 连接对局，完成九次落子，两端均显示黑棋获胜。不同实体设备的验收随发行版工单进行。
