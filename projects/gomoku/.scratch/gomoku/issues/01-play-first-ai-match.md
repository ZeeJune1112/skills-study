# 01: 双击单文件程序，完成人机首局

**What to build:** 玩家双击 Windows 单文件程序即可进入大厅，创建人机房后立即执黑开局。玩家可以完成一局自由五子棋，并在房间内直接悔棋、重开或退出。

**Blocked by:** 无

**Status:** resolved

- [x] 在 Windows 11 x64 上双击自包含的 `Gomoku.exe` 即可启动大厅，无需安装 .NET。
- [x] 创建人机房后，房主执黑、电脑执白，黑棋先行。界面显示玩家棋色、当前轮次、15×15 个交点和合法落子提示。
- [x] 双方依次在空交点落子。越界、占用交点和错误轮次的落子被拒绝。
- [x] 横、竖和两个斜向的五连及长连均判胜，双方无禁手。棋盘落满且无人获胜时判和，终局显示结果并停止落子。
- [x] 对局中可直接悔棋，撤回到玩家最近一次落子之前并恢复为玩家回合。玩家可直接重开，在终局后也能快速开下一局，退出可返回大厅。
- [x] 通过房间会话的公开动作和状态验证落子限制、四种连线方向、长连、和棋及人机悔棋。

## Answer

`5a2f870` 实现首局，7 项房间会话检查通过。在 Windows 11 x64 的隔离桌面启动单个发布版文件，验证人机回合、悔棋、重开和返回大厅。运行环境的 `.NET` 根目录指向不存在的位置。
