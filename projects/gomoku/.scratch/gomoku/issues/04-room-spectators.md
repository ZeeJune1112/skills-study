# 04: 在双人房和人机房实时观战

**What to build:** 两种房间均可在局域网大厅发现。房主在创建时设置观众席数量，来访玩家默认进入观众席，可在对局中途加入并实时看到房间和棋局的变化。

**Blocked by:** 03 发现局域网房间并完成双人对局

**Status:** resolved

- [x] 创建双人房或人机房时可调整观众席数量，默认 5 个。观众席满时新访客收到明确提示，有空席后可以重新加入。
- [x] 访客可从大厅加入人机房，在观众席观看房主执黑、电脑执白的对局。电脑保留对战席，观众不能占用。
- [x] 对局中途入房的观众立即看到当前棋盘、棋手和轮次。之后能实时看到落子、结果及已支持的悔棋和重开操作。
- [x] 通过房间会话验证观众席容量、入房快照、后续状态同步，以及观众无权落子。
