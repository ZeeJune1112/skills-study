# 只看未完成待办

**Status** `ready-for-agent`

## 问题

用现有命令查看待办时，已完成待办也占据列表。使用者每天挑下一件事时，希望能快速看到还没做完的待办。

## 方案

在现有命令上增加 `--active`。使用者可以按需切换到未完成待办视图。

## 用户故事

1. 作为每天查看待办的人，我希望用 `--active` 只看未完成待办，方便决定下一件事。
2. 作为已有使用者，我希望原来的命令仍列出全部待办，保持日常习惯。
3. 作为已做完所有事的人，我希望看到明确的空结果提示，确认列表无需处理。

## 实现决定

- 默认命令继续展示所有待办，顺序保持不变。
- `--active` 只展示未完成待办，保留它们在原始列表中的相对顺序。
- 筛选后没有条目时，保留列表标题并显示「没有未完成任务」。

## 测试决定

从现有命令行入口执行程序，断言使用者看到的输出。沿用项目现有的 CLI 测试方式。验证默认列表、筛选保序、以及全部完成时的提示。

## 范围之外

新增、编辑待办，持久化格式调整，以及为筛选增加排序选项。
